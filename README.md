# Demo Shop — Telegram bot portfolio case

Демонстраційний Telegram-магазин для портфоліо.

## Що реалізовано
- каталог товарів;
- картка товару;
- кошик;
- зміна кількості товарів;
- checkout;
- збір телефону;
- місто та відділення Нової Пошти;
- фінальне підтвердження замовлення.

> Це **demo / portfolio concept**, а не клієнтський проєкт. Реальна інтеграція API Нової Пошти, CRM, онлайн-оплата та адмін-панель можуть бути додані окремими модулями.

## Запуск
1. Встановити Python 3.11+.
2. Створити Telegram-бота через @BotFather і отримати токен.
3. Скопіювати `.env.example` у `.env` та вставити токен.
4. Встановити залежності:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустити:
   ```bash
   python bot.py
   ```

## Як показувати в портфоліо
**Demo Telegram-магазин / e-commerce bot**  
Каталог, кошик, оформлення замовлення, збір контактів і даних Нової Пошти. Архітектура передбачає підключення CRM, платежів та API служб доставки.
